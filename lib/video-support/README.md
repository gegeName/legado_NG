# Video support

中立视频线路、清晰度、过期检查、播放请求和会话版本。NG 继续拥有播放生命周期、自动跳集和进度存储；本模块不创建第二个播放器或后台服务。来源参考 Legado 339e9af 的 VideoPlayViewModel、VideoSource 与播放行为。

每次解析及 UI 切换使用会话修订号，旧源的迟到回调不能覆盖新媒体。字幕/外部音轨通过明确请求传入 Media3 平台模块。真实站点/视频协议及设备播放另验。

已过期的解析结果最多向源重新解析一次，保留所选线路/清晰度和播放位置；第二次仍过期明确失败。重解析前后核对会话版本，换集后的旧结果不能发布。

`VideoRuleAnalysis` 在视频规则执行期间记录规则请求打开的播放网页。状态通过协程线程上下文传播，按解析隔离，供宿主把浏览器调用转为后台嗅探。模块不直接启动或关闭任何 Android 界面；规则外的网页操作保持宿主原行为。
