# Feature backup

Versioned, bounded contributor archive and portable preference validation.
Android preference access and the existing NG backup encryption remain host ports.
Unknown contributors and newer contributor versions are returned intact for preservation.
No cache files, live proxy URLs, executable APK/JARs or runtime handles are exported.

The adapter validates TVBox envelopes, translation configuration and persisted filter selections before applying preferences. The host writes an encrypted `featureModules.json.aes` under NG's OTHER backup category, preserves local trust decisions, and restarts consumers after restore. Existing SCRIPT engine definitions remain in NG's `config.xml`; extension APKs/JARs and transient native resources must be reacquired separately.
